آموزش مفاهیم پایه شبکه

IP چیست؟

IP یا Internet Protocol آدرسی عددی است که به هر دستگاه در شبکه داده می‌شود تا قابل شناسایی باشد.

MAC چیست؟

MAC آدرس سخت‌افزاری هر دستگاه است که منحصر به فرد است و قابل تغییر نیست.

DNS چیست؟

DNS مانند دفترچه تلفن اینترنت عمل می‌کند و نام سایت‌ها را به IP تبدیل می‌کند.

روتر و سوئیچ چیستند؟

روتر برای اتصال شبکه‌ها به هم و سوئیچ برای اتصال دستگاه‌ها در یک شبکه داخلی استفاده می‌شود.
